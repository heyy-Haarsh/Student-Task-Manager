# Student-Task-Manager
Student Task Manager to demonstrate Git Operations

## Feature Branch Plan

Create each feature on its own branch so Git workflows can be demonstrated clearly:

1. **`feature/student-auth`** - Student sign up, login, logout.
2. **`feature/task-crud`** - Create, view, edit, delete tasks.
3. **`feature/task-deadlines`** - Due dates, overdue highlighting, reminders.
4. **`feature/task-priority-status`** - Priority levels and status tracking (Todo/In Progress/Done).
5. **`feature/task-categories-tags`** - Subject/category grouping and custom tags.
6. **`feature/search-filter-sort`** - Search tasks and filter/sort by status, due date, priority.
7. **`feature/dashboard-summary`** - Dashboard with counts, upcoming deadlines, completion stats.
8. **`feature/notifications`** - In-app/email-style reminder notifications.
9. **`feature/collaboration`** - Share tasks or assign group tasks.
10. **`feature/export-import`** - Export/import tasks (CSV/JSON).
11. **`feature/profile-settings`** - Profile update, password change, preferences.
12. **`feature/activity-log`** - Track task actions for audit/history.
